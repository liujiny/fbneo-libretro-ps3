## 部署与启动方式

当前包使用 `/dev_hdd0/game/SSNE10001/USRDIR/`：

- `EBOOT.BIN` 是 Salamander 轻量启动器，不包含 FBNeo 或完整菜单。
- `cores/fbneo_ra1103_test1.self` 包含 FBNeo 和 RetroArch 前端。
- `retroarch-salamander.cfg` 的 `libretro_path` 指向上述核心 SELF。
- exit-spawn 替换进程；不是在启动器中常驻加载 PRX。
- 替换前备份原文件；同时替换启动器和核心，不覆盖用户配置或历史。

前端的增量构建脚本和具体移植说明位于配套前端仓库
`tools/build_ps3_cell.sh` 和 `PS3_UPGRADE_1103.md`。
脚本需要另行准备 Cell SDK、Docker 镜像和 Wine 工具包装器。

- 所有记录的分配失败计数为 0。
- mslug5 被追踪的常驻分配约 91.82 MiB，加载峰值约 107.82 MiB。
- kov 被追踪的第一帧分配约 57.08 MiB，日志最低可用量为 65.66 MiB。
- 各次卸载后的 `system_live`、`native_live` 均为 0。
- 编译配置显示 `pool_size_mb=8`，但这些游戏的实际
  `effective_game_pool_bytes=0`；不能按已分配 8 MiB 池解释。
- `POOL MISS` 后的 `SYSTEM SUCCESS` 表示成功回退系统分配，并非失败。

这些数值不是宿主 Windows/RPCS3 的 RAM 使用量，也不包含完整显存统计。
卸载后用户内存可用量未立即回到加载前，可能有堆保留或未追踪分配；
不能据此证明或排除全程序泄漏。日志不是连续采样，也不能量化轻量 EBOOT
具体节省的内存；还需长时间运行、重复载入和实机验证。
