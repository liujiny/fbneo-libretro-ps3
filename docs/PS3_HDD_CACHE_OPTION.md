# PS3 PGM 硬盘缓存开关

核心选项：`PS3 PGM HDD Cache (Reload Game)`。
配置键：`fbneo-ps3-pgm-hdd-cache`，取值 `disabled`（默认）或 `enabled`。

- 关闭：保留 PGM 精灵颜色和遮罩数据在 RAM 中，不创建硬盘缓存。
- 开启：允许编译时启用的 PGM 颜色/遮罩缓存，仍受数据大小、布局和
  文件创建/分配结果限制。使用 `/dev_hdd0/tmp/fbneo-pgm-{color,mask}.cache`。
- 修改后关闭内容并重新载入；只复位游戏不保证生效。
- 运行中的选项更新仅改变下一次初始化时的请求，不切换活动数据指针。
- 不影响 Neo Geo、即时存档或存档压缩。关闭缓存需要更多 RAM。
- 不需要通过禁止 tmp 写入来关闭缓存，应恢复 tmp 正常写入权限。

测试：核对默认值及两处创建函数的前置门控；使用 Cell SDK 4.75
编译修改对象并链接 SELF。实机需测试默认关闭、开启、游戏中切换后
关闭/重新载入以及存档内存余量，编译成功不代表实机验证通过。
